# ניהול כיתה — תיקי תלמידים

אפליקציה אישית לתיעוד ומעקב אחר תלמידי הכיתה, בעברית ו-RTL מלא. עובדת בטלפון ובמחשב, כולל שימוש ללא אינטרנט. כל המידע נשמר **רק במכשיר שלך** — שום שרת חיצוני לא רואה אותו.

## מה יש כרגע (גרסה ראשונית / MVP)

- הוספת תלמידים (ידנית או ייבוא מ-CSV) ורשימת תלמידים לפי כיתה
- תיק אישי לכל תלמיד/ה עם ציר זמן, שיחות הורים ומעקב פדגוגי
- הוספת תיעוד (אירוע / שיחת הורים / מעקב פדגוגי), כולל שיוך למספר תלמידים וצירוף תמונה/קובץ
- חיפוש וסינון
- מערכת שעות אישית ומשימות
- גיבוי וייצוא/ייבוא נתונים (כפתור 💾 בפינה העליונה)

## איך מנסים את זה עכשיו, במחשב שלך (בלי GitHub, לבדיקה בלבד)

1. חלצי את קובץ ה-ZIP לתיקייה כלשהי במחשב.
2. היכנסי לתיקייה בשורת הפקודה (או פשוט לחצי פעמיים על `index.html`) — הכי אמין זה להריץ שרת מקומי קטן:
   - אם יש פייתון מותקן: פתחי שורת פקודה בתיקייה והריצי `python -m http.server 8000`, ואז פתחי בדפדפן Chrome את הכתובת `http://localhost:8000`.
3. נסי להוסיף תלמיד/ה ותיעוד — ותראי שהכול נשמר גם אחרי רענון הדף.

> לחיצה כפולה ישירה על `index.html` (בלי שרת) עשויה לעבוד באופן חלקי, אבל לשמירת נתונים אמינה מומלץ תמיד להריץ דרך שרת מקומי כמו שתואר למעלה, או — עדיף — להעלות ל-GitHub Pages כמתואר למטה.

## איך מקימים כתובת קבועה (GitHub Pages) — חינמי

כדי שהאפליקציה תהיה זמינה בכתובת קבועה בטלפון ובמחשב, בלי תלות במחשב שלך:

1. פתחי חשבון חינמי ב-[github.com](https://github.com) אם עוד אין לך.
2. צרי **מאגר (repository) חדש וציבורי (Public)**, למשל בשם `class-management-app`. חשוב: המאגר הזה יכיל רק את **קוד** האפליקציה (הקבצים שבתיקייה הזו) — בלי שום מידע על תלמידים.
3. העלי אליו את כל קבצי התיקייה הזו (אפשר בגרירה דרך אתר GitHub, "Add file → Upload files").
4. בהגדרות המאגר (Settings → Pages) בחרי להפעיל GitHub Pages מהענף הראשי (`main`).
5. אחרי דקה־שתיים תקבלי כתובת כמו `https://<שם-המשתמש-שלך>.github.io/class-management-app/` — זו הכתובת הקבועה של האפליקציה שלך.

## התקנה כ"אפליקציה" בטלפון ובמחשב

- **אנדרואיד (Chrome):** פתחי את הכתובת → תפריט שלוש הנקודות → "התקן אפליקציה" / "הוסף למסך הבית".
- **Windows (Chrome):** פתחי את הכתובת → סמל ההתקנה בסרגל הכתובת (או תפריט שלוש הנקודות → "התקן את...").

לאחר ההתקנה האפליקציה תיפתח כמו אפליקציה רגילה, ותעבוד גם ללא אינטרנט (לאחר טעינה ראשונה).

## גיבוי ושמירת היסטוריה (חשוב!)

מכיוון שהנתונים נשמרים רק במכשיר, **חשוב לגבות באופן קבוע**:

1. לחצי על כפתור 💾 בפינה העליונה → "ייצוא גיבוי (הורדת קובץ)". יורד קובץ JSON עם כל הנתונים.
2. שמרי את הקובץ במאגר **פרטי (Private)** נפרד ב-GitHub (למשל `class-data-backup`) — מאגר זה חייב להישאר פרטי, כי הוא מכיל מידע על תלמידים.
3. כדי לעבור בין הטלפון למחשב: יצאי גיבוי מהמכשיר שבו עבדת לאחרונה, והעלי אותו למאגר הפרטי; במכשיר השני, הורידי את הקובץ העדכני ובחרי 💾 → "שחזור מגיבוי".

## מבנה הקבצים

```
index.html       — שלד האפליקציה
css/style.css     — עיצוב
js/db.js          — שכבת אחסון הנתונים (IndexedDB)
js/app.js         — לוגיקת האפליקציה והמסכים
manifest.json     — הגדרות ההתקנה כאפליקציה (PWA)
sw.js             — עבודה אופליין
icons/            — אייקונים
```

## מה עוד לא מוכן (יתווסף בהמשך, לפי הצורך)

- OCR לזיהוי טקסט בתמונות, זיהוי אוטומטי של אירועים חוזרים, דוחות שמורים, וסיכומי AI — ראו "שיפורים עתידיים" במסמך האפיון.
